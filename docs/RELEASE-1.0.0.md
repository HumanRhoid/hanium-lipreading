# 립리딩 모델 v1.0.0

2026-08-26 · 폐쇄형 한국어 문구 15개 인식

---

## 무엇인가

입 모양 영상 한 편을 받아 **정해진 문구 15개 중 하나**로 답한다. 소리는 쓰지 않는다.

```
가래가있어요      배고파요          자세바꿔주세요
간호사불러주세요   보호자불러주세요   진통제주세요
더워요            숨쉬기힘들어요     추워요
도와주세요         아파요            토할거같아요
물주세요           어지러워요         화장실가고싶어요
```

**목록 밖의 말은 인식하지 못한다.** 다른 말을 해도 이 15개 중 하나로 답한다.

## 성능

| | 값 |
|---|---|
| **교차검증 평균** | **0.621** |
| 중앙값 | 0.663 |
| 최저 화자 | 0.258 (s05) |
| 최고 화자 | 0.892 (s03) |
| 우연 수준 | 0.067 (1/15) |

8화자를 한 명씩 검증으로 빼고 3시드씩, 24런의 마지막 에폭 평균이다.

**이 값은 "처음 보는 사람"에 대한 성능이다.** 학습에 참여한 사람이면 더 높다.

**화자별 편차가 크다.** 0.258에서 0.892까지 벌어진다. 촬영 조건과 발화 습관에
따라 실제 체감이 크게 달라진다.

### 이 숫자를 쓸 때의 주의

**최종 모델 자체의 성능은 측정되지 않았다.** 시험 집합을 따로 두지 않았고,
교차검증 값을 보며 설정을 골라 왔으므로 그 값에 이미 맞춰져 있다.
0.621은 **동일 조건에서 기대할 수 있는 값**이지 이 모델의 실측치가 아니다.

## 산출물

```
checkpoints/release192_seed42.pt
checkpoints/release192_seed1.pt
checkpoints/release192_seed7.pt
```

**셋을 모두 써야 한다.** 시드 하나만 쓰면 같은 영상에도 답이 갈린다
(시드 편차 0.0725). 추론이 세 모델의 확률을 평균한다.

각 파일에 문구 목록과 프레임 수가 들어 있어 매니페스트 없이 동작한다.

## 사용법

```bash
python scripts/predict.py 영상.mp4
```

체크포인트가 `checkpoints/release192_seed*.pt`에 있으면 자동으로 셋을 다 쓴다.
다른 곳에 두었다면 직접 지정한다.

```bash
python scripts/predict.py 영상.mp4 --checkpoint a.pt b.pt c.pt --verbose
```

`--verbose`는 15개 문구의 확률을 전부 찍는다. `--cpu`는 GPU 없이 돌린다.

### 입력 조건

| | |
|---|---|
| 형식 | mp4 · avi · mov |
| 화면 | 정면 얼굴. 입이 프레임 안에 완전히 들어올 것 |
| 길이 | 제한 없음. 발화 구간을 자동으로 찾아 60프레임으로 맞춘다 |
| 화질 | 1080p 이상 권장. 720p는 성능이 눈에 띄게 떨어진다 |

얼굴이 검출되지 않으면 그 프레임은 버린다. 한 프레임도 못 찾으면 오류를 낸다.

## 모델

```
입력    60프레임 · 192x96 · 입술 정렬 크롭 · 흑백 + CLAHE
        ↓
3D-Conv 스템          시간축 짧은 범위를 섞는다
        ↓
ResNet-18             프레임마다 512차원 특징
        ↓
BiGRU (은닉 300, 2층)  시간 맥락을 넣는다
        ↓
평균 풀링 + Linear     15개 문구 점수
```

파라미터 14.31M. 학습은 50에폭 고정, AdamW, 코사인 스케줄, EMA 0.998,
label smoothing 0.1, dropout 0.3.

### 전처리

MediaPipe FaceLandmarker로 입꼬리 두 점을 잡아 **닮음 변환**으로 회전과 크기를
맞춘다. 고개가 기울어도 입이 수평으로 들어오고, 카메라 거리가 달라도 입 너비가
일정해진다.

입 벌어짐으로 발화 구간을 찾아 앞뒤 정적을 자르고, 60프레임으로 균등
리샘플링한다.

**추론과 학습이 같은 함수를 쓴다.** 한 줄이라도 다르면 성능이 조용히 떨어진다.

## 한계

**폐쇄형이다.** 15개 문구 전용이고, 그 밖의 말은 인식하지 못한다.
"모르겠다"고 답하지 않는다.

**저화질에 약하다.** 720x1280으로 찍힌 화자 하나가 0.258에 그쳤다.
크롭 개선으로 0.193에서 0.269까지 올렸으나 그 이상은 재촬영 외에 방법이 없었다.

**학습 데이터가 작다.** 8명 1,238클립이다. 매 학습이 40에폭 근처에서 훈련
데이터를 통째로 외운다. 화자 수를 늘리는 것이 가장 확실한 개선이다.

**같은 조건을 다시 돌려도 값이 흔들린다.** 같은 시드 재실행 4쌍에서 SD 0.029,
최대 0.038이었다. v1.0.0부터 cuDNN 결정성을 켜서 이 흔들림을 줄였으나
완전히 없앤 것은 아니다.
