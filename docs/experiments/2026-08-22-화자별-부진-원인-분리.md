# 화자별 부진 원인 분리 · 혼동 구조 60프레임 재측정

일자: 2026-08-22
상태: **s05와 s07의 부진 원인이 다르다는 것 확인** · 크롭 정렬 변경 **미검증**

## 1. 요약

지금까지 s05(0.169)와 s07(0.441)을 "하위 화자"로 묶어 같은 처방을 찾았다.
**그게 안 통한 이유가 나왔다. 원인이 서로 다르다.**

| | 결과 |
|---|---|
| 60프레임 혼동 구조 | 45프레임 결론이 뒤집혔다. 화자 간 공통 패턴이 생겼다 |
| 음절 수 가설 | **기각.** 8음절이 오답률 30.0%로 가장 낮다 |
| 문구 3개 제외 | +0.067. 단 s05는 +0.006으로 찍기 상승분보다 작다 |
| s05 원인 | 화질 추정 (랜드마크 0.322 > 영상 0.19) |
| s07 원인 | 조음 방식 추정 (턱 고정·치아 접촉). **육안 관찰이며 미측정** |
| 크롭 정렬 | 축 정렬 사각형 → 닮음 변환, 192×96. **학습 결과 없음** |

모든 수치는 재학습 없이 `cv60_*` 체크포인트 24개로 추론만 해서 얻었다.
각 체크포인트가 자기 검증 화자를 안 보고 학습했으므로 화자 독립 조건은 유지된다.

## 2. 혼동 구조 — 45프레임 결론이 뒤집혔다

[2026-08-19 §4.4](2026-08-19-오차-분해.md)의 결론은 "여덟 명의 1위가 전부 다르다,
겹치는 것이 하나도 없다"였다. 60프레임에서는 겹친다.

| 화자 | 1위 혼동 |
|---|---|
| s01 | **물주세요 ↔ 추워요** |
| s03 | **물주세요 ↔ 숨쉬기힘들어요** |
| s04 | 간호사불러주세요 ↔ 보호자불러주세요 |
| s05 | 간호사불러주세요 ↔ 배고파요 |
| s06 | 더워요 ↔ 어지러워요 |
| s07 | **물주세요 ↔ 추워요** |
| s08 | **물주세요 ↔ 숨쉬기힘들어요** |

여덟 중 넷의 1위가 `물주세요`이고 두 쌍이 겹친다.

```
합계 상위 5쌍 (24런, 오답 1,401건)
  79  물주세요 ↔ 추워요
  72  물주세요 ↔ 숨쉬기힘들어요
  55  더워요 ↔ 추워요
  51  숨쉬기힘들어요 ↔ 추워요
  46  더워요 ↔ 어지러워요
```

### 2.1 음절 수 가설 기각

[2026-08-18 §3.2](2026-08-18-오답-구조-분석.md)는 "8음절 문구 3개가 오답 25개 중
13개를 만든다"고 적었다. 60프레임 전수 측정에서는 **정반대**다.

| 음절 | 오답률 |
|---|---|
| 3음절 | 42.5% |
| 4음절 | 39.6% |
| 5음절 | 49.6% |
| 6음절 | 34.0% |
| 7음절 | 33.7% |
| **8음절** | **30.0%** |

8음절 셋(간호사불러주세요 40.5%, 화장실가고싶어요 33.3%, 보호자불러주세요 16.7%)이
가장 낮다. **길이로는 설명되지 않는다.** 같은 4음절인데 물주세요 72.3%,
배고파요 6.5%로 11배 차이가 난다.

### 2.2 문구별 오답률

```
72.3%  물주세요        51.9%  진통제주세요     33.3%  화장실가고싶어요
58.9%  추워요          44.2%  어지러워요       31.7%  숨쉬기힘들어요
54.9%  도와주세요       41.9%  더워요          27.1%  토할거같아요
                       40.5%  간호사불러주세요   26.2%  아파요
                       35.7%  자세바꿔주세요    21.7%  가래가있어요
                                              16.7%  보호자불러주세요
                                               6.5%  배고파요
```

### 2.3 원순모음 가설 (미검증)

상위 혼동 쌍에 묶인 문구는 앞부분이 전부 입을 오므리는 모음이다.

```
물주세요       물(ㅜ) 주(ㅜ)
추워요         추(ㅜ) 워(ㅝ)
더워요         워(ㅝ)
숨쉬기힘들어요   숨(ㅜ) 쉬(ㅟ)
어지러워요      워(ㅝ)
```

낮은 쪽은 반대다. `배고파요`는 배(ㅐ)·파(ㅏ)로 크게 벌리고 `가래가있어요`는
가(ㅏ)·래(ㅐ)다. `보호자불러주세요`(보ㅗ 호ㅗ)가 원순인데도 16.7%로 낮은 것이
반례이나 8음절이라 뒤에 구별 정보가 남는 것으로 보인다.

**문구 이름을 읽고 세운 가설이며 측정하지 않았다.** 확인하려면 문구를 모음
기준으로 묶어 오답률을 다시 세면 되고, 재학습 없이 가능하다.

## 3. 문구 제외 — 마스킹으로 측정

`scripts/analyze_confusion.py --drop`을 추가했다. 뺄 문구를 정답에서 제외하고
예측 후보에서도 `-inf`로 막는다. 문구를 줄여 다시 학습했을 때의 결정과 같아진다.

정답에서 빼기와 후보에서 막기 중 **하나만 하면 틀린다.** 건너뛰기만 하면 모델이
여전히 뺀 문구를 답으로 낼 수 있고, 막기만 하면 없는 문구를 채점하게 된다.

물주세요·추워요·도와주세요 셋을 뺐다. 오답률 상위 3개다.

| 화자 | 15문구 | 12문구 | 차이 |
|---|---|---|---|
| s09 | 0.647 | 0.782 | +0.135 |
| s08 | 0.777 | 0.892 | +0.115 |
| s03 | 0.613 | 0.718 | +0.105 |
| s07 | 0.441 | 0.516 | +0.075 |
| s01 | 0.641 | 0.699 | +0.058 |
| s04 | 0.833 | 0.861 | +0.028 |
| s06 | 0.873 | 0.891 | +0.018 |
| **s05** | 0.169 | 0.175 | **+0.006** |
| 전체 | 0.623 | 0.690 | +0.067 |

찍기 확률이 0.067에서 0.083으로 **0.016 올랐는데 s05는 0.006만 올랐다.**
찍기 대비로는 2.52배에서 2.11배로 **떨어졌다.**

**어느 문구를 빼도 s05는 올라오지 않는다.** [2026-08-21]의 s05 제외 실험
(−0.016)에 이은 두 번째 확인이다.

화자 간 최대−최소는 0.704에서 0.716으로 **벌어졌다.**

### 3.1 두더지 잡기

물주세요를 빼면 그 자리를 다음 순번이 채운다.

```
빼기 전 1위    물주세요 ↔ 추워요        79
빼고 난 후 1위  더워요 ↔ 숨쉬기힘들어요    48
```

화자별 1위도 8명 중 6명이 바뀌었다. 오답률 1위는 `진통제주세요` 51.6%가 된다.
`숨쉬기힘들어요`는 자기 오답률이 12.5~30.5%로 낮은데 상위 10쌍 중 5~6개에
등장한다. 다른 문구가 그쪽으로 빨려 들어간다는 뜻이다.

### 3.2 s05를 학습에서도 빼면

`no5_*` 체크포인트(7화자 × 시드 1·7)로 같은 측정을 했다. 12문구 기준 **0.733**이다.
s05를 학습에 포함하고 채점에서만 뺀 0.766보다 **낮다.**

| 화자 | s05 학습 포함 | s05 학습 제외 | 차이 |
|---|---|---|---|
| s08 | 0.892 | 0.954 | +0.062 |
| s09 | 0.782 | 0.786 | +0.004 |
| s01 | 0.699 | 0.690 | −0.009 |
| s06 | 0.891 | 0.876 | −0.015 |
| s04 | 0.861 | 0.838 | −0.023 |
| s07 | 0.516 | 0.474 | −0.042 |
| **s03** | 0.718 | **0.534** | **−0.184** |

평균 −0.030인데 거의 전부 s03에서 나온다. s03은 시드 편차가 0.158로 가장 크고,
학습 데이터가 12% 줄자 무너졌다.

**왼쪽은 3시드, 오른쪽은 2시드라 엄밀한 비교가 아니다.** 방향만 읽어야 한다.

**s05 데이터는 학습에 남기고 평가에서만 빼는 편이 유리하다.**

## 4. s05와 s07은 다른 이유로 낮다

| 화자 | 정확도 | 원인 추정 | 근거 | 개선 가능성 |
|---|---|---|---|---|
| s05 | 0.169 | 화질 | 랜드마크 0.322 > 영상 0.19. 다른 화자는 반대 | 재촬영이면 가능 |
| s07 | 0.441 | 조음 방식 | **육안 관찰만** | 전처리·모델로는 불가 |

s07은 60프레임 크롭을 눈으로 보면 턱을 거의 쓰지 않고 치아를 붙인 상태로
발음한다. 입술 표면만 움직인다.

### 4.1 lip_openness는 이것을 못 잰다

`lip_openness`는 위아래 입술 사이 거리를 입 너비로 나눈 값이다. 턱을 안 쓰고
입술만 벌려도 커진다.

| 문구 | s06 변동폭 | s07 변동폭 |
|---|---|---|
| 추워요 | 0.163 | **0.301** |
| 토할거같아요 | 0.302 | 0.285 |
| 숨쉬기힘들어요 | 0.220 | **0.290** |

**숫자상 s07이 오히려 더 크다.** 지표와 육안 판단이 어긋난다. 그 지표가
조음의 실제 크기를 재지 못한다는 뜻이며, 발화 구간 트리밍도 이 값에 의존한다.

### 4.2 미측정

s07의 턱 사용량을 재려면 턱 랜드마크(예: 152번)와 코 기준선 사이 거리를
프레임마다 재야 한다. **아직 하지 않았다.** 위 결론은 60프레임 크롭 이미지를
사람이 보고 내린 판단이다.

## 5. 크롭을 닮음 변환 정렬로 바꿨다 (미검증)

### 5.1 예전 방식의 문제

`LIP_LANDMARKS` 21점의 최소·최대로 축 정렬 사각형을 만들고 50% 여백을 붙였다.

- **고개가 기울면 입이 대각선으로 들어간다.** 같은 발음도 화자마다 다른 그림이 된다
- **상자 종횡비가 화자마다 다른데** 112:80 = 1.4:1에 밀어 넣어 가로가 세로보다
  더 눌린다. 측정된 입술 상자 비율은 1.73:1이었다
- **21점에 윗입술 바깥 점이 없다.** 목록은 입꼬리·아랫입술·안쪽 윤곽뿐이라
  사각형 윗변이 사실상 입꼬리 높이가 된다
- **입을 벌리면 상자가 커지고 다물면 작아진다.** 발화 중 기준선이 움직인다

### 5.2 바꾼 내용

입꼬리 두 점(61, 291)으로 회전·배율·위치를 정한다.

```
회전   두 점을 잇는 선을 수평으로
배율   두 점 사이 거리 = 출력 가로의 0.5 (96px)
중심   입술 21점 무게중심을 출력 정중앙에
크기   112×80 → 192×96 (연산 2.1배)
```

합성 랜드마크로 검산했다. 기울어진 입을 넣으면 세로 차이 0.0000, 입 너비
정확히 96.00px, 중점이 (96.00, 48.00)에 놓인다.

### 5.3 남은 결함 — 윗입술 잘림

7화자 321프레임에서 입꼬리 선 기준 입술 세로 범위를 쟀다.

```
윗입술 위    중앙 0.259 · 최대 0.399   (입 너비 = 1)
아랫입술 아래  중앙 0.328 · 최대 0.519
입술 전체    중앙 0.578 · 최대 0.845
```

입 너비 96px이면 입술 세로가 최대 81px인데 크롭이 96px이다. **여유가 위아래
7.5px씩뿐이다.** 그리고 21점 무게중심은 아래로 치우쳐 있다.

| 중심 기준 | 윗입술 잘림 | 아랫입술 잘림 |
|---|---|---|
| 21점 무게중심 (현재) | 6/152 | 0/152 |
| 입꼬리 중점 | 0/152 | 2/152 |

**어느 쪽도 완전하지 않다.** 입 너비 비율을 0.42로 낮추면 위아래 여백이
14px씩 되나 **적용하지 않았다.**

### 5.4 측정과 육안 판단이 어긋난다

42프레임 표본에서 예전 방식은 윗입술을 **81%** 잘랐고 새 방식은 9.5%였다.
그러나 실제 크롭 이미지를 사람이 보았을 때 **잘림이 뚜렷하지 않다는 판단**이 나왔다.

이 측정은 MediaPipe 랜드마크 **0번을 윗입술 꼭대기, 17번을 아랫입술 바닥**으로
가정한다. **그 인덱스를 검증하지 않았다.** 틀리면 위 세 절의 수치가 전부 무효다.
