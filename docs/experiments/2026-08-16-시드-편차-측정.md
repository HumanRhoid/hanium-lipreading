# 시드 편차 측정

일자: 2026-08-16
상태: 진행 중

## 1. 배경

이전 회차에서 교차검증 평균 0.420을 얻었으나, 모두 `seed=42` 단일 실행이었다.
같은 설정으로 시드만 바꿔 세 번 돌린 예비 실험에서 s04가 0.340~0.433으로
**0.093 흔들렸다.** 이 폭은 화자 간 차이와 비슷한 수준이라, 단일 실행으로 매긴
화자 순위나 설정 비교를 신뢰할 수 없다.

7화자 × 3시드 = 21회를 돌려 각 화자의 신뢰구간을 확보한다.

## 2. 설정

이전 회차와 동일하다. 시드만 `[42, 1, 7]`로 반복한다.

```python
epochs=80
batch_size=16
learning_rate=2e-4
hidden_dim=300
num_layer=2
dropout=0.3
label_smoothing=0.1
grad_clip=1.0
ema_decay=0.998
```

## 3. 시드가 정하는 것

시드 하나가 세 가지를 동시에 고정한다. 개별 지정은 불가능하다.

- 가중치 초기값 (`torch.manual_seed`)
- 데이터 순서 (`DataLoader shuffle`)
- 증강 변형 선택

증강 난수가 시드를 따르지 않던 문제는 이전 회차에서 수정했다.
`dataset.py`에서 torch 난수로 시드를 뽑아 worker마다 다르되 전체는 재현되도록 했다.

## 5. 드러난 문제

**학습이 초기 조건에 지나치게 민감하다.** 같은 데이터, 같은 설정인데 출발점에
따라 0.325와 0.599로 갈린다.

원인 후보는 셋이다.

**학습률이 높다** — `2e-4`는 배치 16에 맞춰 올린 값이다. 초반 보폭이 크면 나쁜
방향으로 크게 이동한 뒤 회복하지 못할 수 있다.

**warmup이 없다** — 무작위 초기값 상태에서 처음부터 최대 학습률을 쓴다. 보통
초반 5~10%를 낮은 학습률로 시작해 서서히 올린다.

**데이터가 적다** — 927개로는 손실 지형이 울퉁불퉁해 출발점에 따라 도착점이
갈린다. 근본 원인이며 단기간에 해소하기 어렵다.

## 6. 다음 회차 과제

**warmup 도입 후 편차 재측정**이 우선이다. 성능이 아니라 **편차를 지표로 삼는
실험**이다.

```python
warmup = torch.optim.lr_scheduler.LinearLR(
    optimizer, start_factor=0.1, total_iters=5
)
cosine = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs - 5)
scheduler = torch.optim.lr_scheduler.SequentialLR(
    optimizer, [warmup, cosine], milestones=[5]
)
```

학습률을 `1e-4`로 되돌리는 방안도 함께 검토한다.

**앙상블**도 후보다. 시드마다 결과가 크게 다르다는 것은 모델들이 서로 다른
실수를 한다는 뜻이므로, 확률 평균이 효과를 낼 조건이다.

## 7. 보고 기준

이 회차가 끝나면 **화자별 평균과 시드 편차 평균**이 나온다.

시드 편차 평균이 화자 간 편차보다 크면, 화자별 순위를 논하는 것 자체가
의미 없다는 결론이 된다. 그 경우 전체 평균만 보고하고 화자별 비교는 빼야 한다.
